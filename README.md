# ☕ Uvia Coffee - Web Application

A modern, responsive web application for **Uvia Coffee** designed to enhance customer experience by making ordering fast, effortless, and seamless.

---

## 🌟 Key Features

* 📋 **Interactive Menu:** Explore all coffee drinks, beverages, and items with detailed descriptions and prices.
* 🛒 **Pre-Order Cart:** Add items to your cart ahead of time and present your prepared order directly to the cashier for quick checkout.
* 📍 **Branch Locator:** Discover nearby Uvia Coffee locations, view opening hours, and get directions.
* ℹ️ **About Uvia Coffee:** Learn about the story, brand value, and vision behind Uvia Coffee.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript
* **Backend:** PHP
* **Database:** MySQL
